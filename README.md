## Project Description 📌
<!-- Standard : Project Description  -->
This project is an interactive, animated hidden search widget. When the search button is clicked, the search input expands smoothly and automatically focuses for user input, and collapses when clicked again.

---
---
---

## Features 🌏
<!-- Standard : features  -->
- Responsive and modern UI
- Smooth CSS expansion transitions
- Auto-focus on input field upon activation
- Font Awesome search icon integration
- Lightweight and modular component structure
